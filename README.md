# The Inn Between

В первой главе «Шесть грошей» хозяин разбирает долг за три смены у печи. За каждую из них расписался сержант, а работала покойная сестра пекаря. Пути к Лиде и то, что останется после неё в таверне, зависят от ответов хозяина.

## Запуск

**ПК.** Открой `game/index.html` в Edge или Chrome. Щёлкни по карточке решения, потяни портрет в сторону или нажми ← / →. Последствие откроется на светлом листе. Чтобы пригласить следующего гостя, перелистни его, коснись листа или нажми «Следующий гость». Клавиши ← / → также перелистывают страницу.

**Android Studio.** Открой папку `android` как проект. Для Gradle JDK выбери Microsoft OpenJDK 17. Дождись синхронизации, выбери `InnBetween_API_35` в списке устройств и нажми Run. Исходники экрана общие с ПК, поэтому после редактирования достаточно пересобрать приложение.

**Из PowerShell.** Из корня выполни `powershell -ExecutionPolicy Bypass -File .\tools\android-test.ps1`. Команда собирает APK, создаёт AVD Pixel 5 при первом запуске, дожидается загрузки, устанавливает игру и открывает её. Параметр `-Headless` скрывает окно эмулятора для автоматической проверки. APK находится в `android/app/build/outputs/apk/debug/app-debug.apk`. На физическом Android 8+ можно установить его через Android Studio или adb.

## Инструменты на другом ПК

Установи Android Studio и Microsoft OpenJDK 17. Через SDK Manager установи Android SDK Command-line Tools (latest), Platform-Tools, SDK Platform 35, Build-Tools 35.0.0, Android Emulator и Google APIs x86_64 System Image API 35. Скрипт найдёт SDK по ANDROID_HOME либо в стандартной пользовательской папке. Для x64-эмулятора Windows нужен работающий WHPX. Сборка закрепляет Android Gradle Plugin 8.8.2 и Gradle 8.10.2. Интернет нужен при первой установке инструментов и сборочных зависимостей. Сама игра автономна.

## Редактирование

- `PROJECT_PROMPT.md` — концепция таверны, голоса пяти гостей и сценарий главы.
- `game/chapter.js` — 14 встреч основной истории. Каждая сторона карты имеет собственный текст последствия. `next` у ответа или встречи задаёт продолжение, `interlude` оставляет перед ним один обычный визит. `variants` меняет слова гостя по флагу прошлого решения, `mark` запоминает сюжетную веху после пережитого выбора.
- `game/cards.js` — 14 бытовых встреч и продолжений, включая историю несостоявшейся свадьбы. У каждого решения есть ответ хозяина, изменения шкал в шагах и текст на пергаменте. `requires` задаёт условие, `once` убирает повтор, `weight` задаёт частоту. `seals` выбирает рисунки ответов, `atDoor` показывает улицу за дверью.
- `game/config.js` — баланс, концовки, гости и звуковые слоты. У гостя отдельно заданы имя, занятие, портрет и фон карточки. Для звука дождя укажи `audio/rain.ogg` в поле `rain` и положи файл в `game/audio`. Пустые слоты не загружаются.
- `game/engine.js` — выдача, жесты и применение выбора. `game/game.css` задаёт вид карточек и адаптивную компоновку.
- `game/portraits/morwen.gif` — исходный портрет Морвен. Текущие игровые иллюстрации, фон, рубашка и значки находятся в папке game/art.
- `ART.md` — правила рисования и проверки игровых SVG. Там же сохранён процесс подготовки пиксельных GIF и спрайтов с помощью `tools/portraits.py`.

## Смерть и гостевая книга

Любая из четырёх шкал при 0 или 100 завершает партию. Если выбор приводит к двум границам сразу, причиной смерти станет та, до которой перед ходом оставалось меньше пунктов. При равном расстоянии решает порядок значков слева направо. Череп отмечает причину над шкалой. Смертельный выбор сразу открывает его иллюстрацию.

В конце гостевая книга показывает памятную карту и число принятых решений. Каждый визит даёт 10 очков. По одной звезде стоимостью 30 очков даётся за найденного свидетеля, разговор с Лидой и завершённую развязку. После завершения главы таверна продолжает принимать обычных гостей. Новая партия начинает новую запись.
