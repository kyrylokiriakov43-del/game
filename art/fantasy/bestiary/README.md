# Старые боги — эталон бестиария

Утверждённое пользователем направление: [таблица 12 образов](reference-sheet.webp). Стиль — крупные геометрические цветовые плоскости, ограниченная палитра, матовая бумажная фактура, тёмная арка. Без рамок, текста, UI, мелкой детализации и реалистичных эффектов. [Действующий дизайн-код](../../../.agents/skills/inn-between-art/references/fantasy-card-style.md).

Таблица — концепт, а не атлас для нарезки. Каждый образ перерисовывается самостоятельной квадратной иллюстрацией. Игровой экспорт WebP 512×512. Сохранять характерный силуэт, цвет, анатомию, предмет сцены; для полноценного подключения сначала утвердить реплику и выборы. Здесь лежат самостоятельные иллюстрации-кандидаты, не подключённые к действующей колоде. Не заменять существующие SVG без согласования сценария и внешности.
