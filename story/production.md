# От просьбы гостя до проверенной встречи

## Что показала сверка

Срез локальной игры при разборе — 60 встреч, 49 иллюстраций по проверке проекта и пять атласов. Дизайн-аудиты `deep-research-report(11).md` и `(13).md` совпали по SHA-256 и описывают архив с 52 встречами. Восемь появившихся с тех пор карт — две встречи после ремонта, два возвращения после паводка и четыре карты ночного рынка. Литературный разбор `(12).md` помогает оценить голоса, предмет и память выбора. Его три предложенные ветки имеют статус идей.

| Наблюдение в текущей версии | Производственное решение |
|---|---|
| В редакторской папке до сих пор обсуждаются зарубки на совке. На игровой карте давно выемка под левую руку. | Для каждой правки сначала вызвать `canon ID`. В `haft` Элиас теперь называет три утра, когда сам получал угли от Лиды. Рукоять позволяет узнать работницу, число смен подтверждает свидетель. |
| Возвращения после парома и ремонта уже работают. Дополнительная очередь дублировала бы существующую. | Выбирать между немедленным переходом, назначенной встречей и возвратом по темпу конкретной сцены. Для обещанного визита проверять игру при занятой очереди. |
| В рынке пламя зависит от покупки. Одна и та же «пекарня» может требовать разных фонов и разной атмосферы. | Передавать художнику и звуку ID и состояние предмета после выбора. Проверять тишину в холодной печи наравне с самим рисунком. |
| Аудиофайлы лежат рядом, но музыка, атмосфера и короткие звуки выбираются разным кодом. | В задании указывать, что играет циклом в комнате и что звучит ровно один раз на входе или на листе последствия. |
| Данные колоды уже можно прочесть отдельно от интерфейса. Список скриптов приходилось синхронизировать с HTML вручную. | Проверка арта и чтение канона теперь берут порядок файлов из страницы игры. Текстовую развилку можно сыграть с клавиатуры до появления первого PNG или OGG. |

Это аудит подготовки контента. Для оценки частоты повторов, понятности шкал и темпа нужны отдельные наблюдения за игроками. У нас пока нет такого замера для этой итерации.

## Как проходит один эпизод

| Этап и исполнитель | Что получает следующий участник | Когда переходить дальше |
|---|---|---|
| Замысел · сценарист | Короткая записка в `story/drafts/<эпизод>.md`: кто пришёл, чего хочет сейчас, что знает игрок, цена каждого ответа и вещь, по которой узнают последствие. | Можно произнести обе стороны разговора, понятно, зачем выбирать. |
| Черновик · сценарист и редактор | Соседний JSON с текстом, стабильными ID, эффектами и связями. Образец — [«Семь минут»](drafts/seven-minutes.json). | Пройти обе стороны каждой развилки. Убрать ответы, которые обещают одно действие, а показывают другое. Пометить в записке версию текста, готовую к изготовлению. |
| Задания · художник, звукорежиссёр и композитор | По одной строке на ID или общее состояние. Указать существующий файл либо новый материал, момент появления и способ проверки. Все три работы можно вести одновременно по одной редакции сценария. | Из каждой строки ясно, что именно должно измениться после свайпа. Строка «тишина» или «оставить текущую тему» тоже завершает решение. |
| Подключение · разработчик | Массив `cards` черновика уже имеет форму данных игры. При переносе сохранить ID, тексты, эффекты и переходы. Добавить вход в обычную выдачу или вызвать его из существующей карты. Продолжения поместить в колоду, для `next` зарегистрировать их также в `chaptersById`. | Проверить фактическую достижимость через обычную партию, цену выбора и возврат к прежним назначениям. После переноса записать в записке путь к игровому JS. Дальнейшая редактура ведётся там. |
| Приёмка · редактор и разработчик | Обе ветви на телефоне и ПК, кадр при свайпе, проверка звука при повторном входе, отключённом звуке и смене локации. | `python tools/check_art.py` и `node tools/test_visits.cjs` проходят. Для нового пути добавить в проверку прохождение от его игрового входа. Зафиксировать, где сыграли люди и что проверила автоматика. |

Если после начала отрисовки правится реплика, сравни старое и новое действие по ID. Замена имени или ритма фразы иногда требует только повторного чтения на маленьком экране. Замена горшка на сковороду затронет лицо карты, жест гостя и возможный звук посуды. Отметь в записке именно эти задания.

## Читка без ресурсов

У архивной читки «Семи минут» есть метка `"publishedStory": "seven-minutes"`. Она разрешает совпадение ID только с картами этой опубликованной истории. При копировании примера для новой ветки убери эту метку.

Из корня репозитория с Python 3 и Node.js:

```sh
python tools/story.py draft story/drafts/seven-minutes.json --play
python tools/story.py draft story/drafts/seven-minutes.json --path LR
python tools/story.py canon haft
```

Для новой короткой ветки скопируй пару JSON + записка из [образца](drafts/seven-minutes.md). В JSON укажи `title`, ID входа `entry` и массив `cards`. Для карты нужны ID, ключ существующего гостя, реплика и два ответа в порядке L/R. У каждого ответа есть `text` и `effects` (в шагах шкал, допустимо `{}`). Добавь `passage`, когда игроку стоит задержаться на случившемся. Если результат станет виден при следующей встрече, пропусти поле. Так устроен ужин караула в игровой редакции. Необязательный `visitNow` или `returnVisit` ведёт к ID в том же черновике. Без перехода читка завершается. Для нового гостя можно сначала провести читку за подходящего существующего персонажа либо добавить голос в `guests` с будущим оформлением при интеграции.

Читка проверяет все локальные переходы, число ответов, шкалы, повторы ID, циклы и недостижимые из входа карты. Она пропускает промежуточных гостей между обещанием и его исполнением. Баланс, смерть, условия и варианты действующих глав проверяются в игре. Для сложной правки существующей главы удобнее работать с нативными полями движка и браузерной проверкой.

## Поля задания на ресурсы

Привяжи к ID жест и состояние предмета **до** ответа. Укажи эталон лица, композицию и деталь, которую нужно разглядеть при ширине карты 200 px. Для SFX укажи источник в мире, триггер `arrivalSound` или `passageSound` нужной стороны и случаи тишины. Для музыки укажи комнату, существующую тему или задачу композитору, точку входа, повтор и выход. Локальные OGG, уровни и плавные переходы задаёт [аудиодвижок](../game/audio.js). Форматы и кадрирование задаёт [художественный профиль](../ART.md). [Заполненная ведомость](drafts/seven-minutes.md) показывает, какие заказы остаются после сверки библиотеки.
