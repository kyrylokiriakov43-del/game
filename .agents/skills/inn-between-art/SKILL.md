# Графика The Inn Between

Найди корень игры по `ART.md`, `game/config.js` и `game/index.html`. Прочитай в [ART.md](../../../ART.md) строку таблицы для нужного элемента и раздел «Проверка в игре». Используй текущие файлы из `game/art/` как образцы. Если просят пиксельный GIF, перейди к архивному процессу в том же документе.

**Бриф.** Перед рисованием найди эпизод, где элемент увидит игрок. Укажи ID, роль изображения, одно действие или предмет, по которому его можно узнать, файл-образец и участок, занятый интерфейсом. Для портрета посмотри лицо вместе с его парным фоном. Для серии определи общие крупность, направление света и положение плеч. Меняй между гостями силуэт, жест и примету места.

Например, для эпизода `haft` ориентиры — `cooper.svg` и `workshop.svg`. Задача художнику: «Элиас протягивает хозяину совок рукоятью вперёд. В миниатюре должны различаться хват и выемка под большой палец. Сохрани лицо и одежду Элиаса. Помести руку ниже лица, оставь фон отдельным слоем. Проверь, видно ли совок при предпросмотре обоих ответов». По аналогии выбери деталь из текста запрошенной сцены.

**Подключение.** Проверь, какие эпизоды используют исходный ресурс. Замена портрета в `guests` меняет все встречи с гостем. Если изменение задумано только для одной сцены, сохрани общий образ героя и проверь область действия привязки. Для значка или панели определи индекс в действующем атласе и место, откуда игра его читает. Оставь слова героя, ответы и последствия в текстовых полях игры.

**Приёмка.** Из корня выполни `python tools/check_art.py`. Затем открой изменённый эпизод через `game/index.html` на ширине телефона и на ПК. Проверь деталь из брифа в масштабе карты, подпись, перекрытие при свайпе и обе стороны ответа. Для декорации за колодой проверь видимую после кадрирования часть, для анимации — неподвижный кадр с уменьшенным движением. Укажи, какой файл и какое игровое состояние проверены.
