# Ночной рынок и печь Агаты

Встреча `market-scales` использует рисунки из авторского набора `inn-city-locations-v02`. [Площадь](../../../../game/art/market-room.svg) занимает задник, [весы](../../../../game/art/market-scales.svg) — всю карту Саввы. Гиря и поленья должны различаться на ширине карты 200 пикселей, когда сверху открыта плашка свайпа.

Две карты возвращения сделаны в ImageGen по портрету `baker-preview.png` из набора спрайтов и [карте Рутгера](../../../../game/art/quarters-ledger.webp). Платок, рукава и фартук помогают узнать Агату. Пекарня получает новый задник только при нехватке топлива. Четыре возможных блюда остаются в тексте, пока игрок выбирает. [Кадры из игры](../../../../art/preview-night-market.webp)

## Общий запрос для карт

> Create one square, edge-to-edge editorial cut-paper illustration used as a medieval inn decision card. Reference 1 fixes the baker Agata: middle-aged, ochre skin, dark cropped hair, cream kerchief with rusty red stripe and knot, muted teal sleeves, brown apron. Reference 2 fixes the restrained angular hand cut silhouettes, woodblock texture and large readable shapes of this game. No letters, numbers, borders, UI or typography. Simple full-bleed scene, low detail, matte paper, visible gestures and tools in middle 65% for small phone.
